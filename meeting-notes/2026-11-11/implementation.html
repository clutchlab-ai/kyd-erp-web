本次查核補上的 3 項修正

證件總數一致

高層逾期數排除被續辦取代的舊件，以及非在職人員；與目前有效證件總表一致。

人力衝突可視化

日曆與崗位清單共用計算：分開顯示已安排、排班無衝突、請假衝突、尚無已發布班次與需確認人力。跨午夜班次按實際起訖判斷，銷假／換代班後重新計算。部分時段衝突不等於全天缺勤。

明細與操作權限一致

部門主管的班表、補卡、換代班、工作回報、崗位安排、選人欄位及待辦限於所屬範圍；直接操作也檢查權限。全公司月結保留給獲公司授權的人資與管理層。

原有 8 組模組保留並驗證

人事異動考核管理培訓與獎懲工程與專案採購作業財務會計薪資與社保行政交辦

這些功能在先前示例已有建置，本輪保留並做流程回歸，並非全部重新開發。工程、採購、財務仍保留；供應商留在採購內、工程文件留在專案內，沒有擅自加回已收起的左側選單。

操作前先做這三步

  1. 開啟電腦或手機示例。電腦用上方身分選單；手機點上方姓名旁的「切換」。
  2. 選角色與可用公司，再進模組。換角色只切視角，已儲存單據不會消失；正式登入權限不會跟著示例角色改變。
  3. 儲存／送出後，到下一個角色的「待我簽核」接手同一筆。示例日期固定為 2026-11-04；測試排班時以頁面顯示日期為準。

13 條操作路徑

01請假、外勤、加班、銷假
  1. 員工進入「假勤申請」，選申請種類；填日期、時數、事由、交接及該種類需要的欄位，儲存後送出。
  2. 切換送出後顯示的處理角色，從「待我簽核」開同一筆單據；可退回並填原因，或複核後交下一層。
  3. 退回時切回原申請人，補充原單後重送；最後一層核准後，員工看結果，人資總表與班表更新。
  4. 已核准請假可提出銷假，另經流程核准後恢復額度。可先設定一／二／三層各試一次；未設定情境沿用示例路線。
前往操作 →
02排班、請假衝突與崗位人力
  1. 人資在月曆選日期，按「安排班次」；選同公司授權員工與班別，送交另一位主管發布。
  2. 人資主管從待辦發布或退回；員工在自己的班表看到已發布結果。草稿不當作已發布班次。
  3. 在同日核准一筆與班次重疊的請假，再回到月曆：日期顯示「人力待查」，右側顯示請假衝突。
  4. 點「查看崗位安排」，核對已安排人員、未發布班次及衝突；調整人力後送審。部分請假仍由主管確認替班時段，不自動認定全天缺勤。
前往操作 →
03換班與代班
  1. 員工選自己的已發布班次，選接班人；互換班次需同時選對方的班次，填原因後送出。
  2. 切換接班人，同意或婉拒；同意後交與雙方無利益衝突的授權主管審核。
  3. 主管核准才更新班表。已有班次衝突、原班次已被修改等情況會阻擋；退回可修改同一筆後再送。
  4. 核准後回月曆與崗位安排核對新接班人；崗位名單不會被偷偷替換，仍需核對現場安排。
前往操作 →
04補卡與月結
  1. 員工提出補卡日期、類型、時間及原因；授權主管可核准或退回，核准才產生帶來源標記的補卡紀錄。
  2. 人資選已結束月份，逐項核對異常並處理待審申請；未完成項目會阻擋送審。
  3. 人資送出，人資主管獨立核准並鎖定；如需補改，先重開月結，舊版快照與歷史仍保留。
  4. 部門主管可看自己部門的工時與假勤總表，不能直接鎖定全公司的月份。
前往操作 →
05證件、續辦與通知
  1. 人資進全員證件總表，核對勞動合約、護照、工作許可、簽證與保密協議；未登錄先確認是否適用。
  2. 點證件狀態，記錄補件或續辦、下次跟進日期；收到新證件才更新期限。只記「續辦中」不會讓過期證件變有效。
  3. 切換該員工，可由右上鈴鐺查看自己的到期提醒並開明細。人資可看授權範圍內的跟進。
  4. 此處已提供站內通知；Email 與手機推播並未接通。
前往操作 →
06人事異動與生效
  1. 人資選部門／職務調整、新進到職、試用轉正、跨公司調動、離職交接或復職，各有獨立情境與表單。
  2. 填異動內容及生效日 → 送複核 → 切人資主管 → 複核或退回 → 切 CEO 核准。
  3. 核准後切回人資，在生效日到達時「確認生效」；不是核准當下就自動改任職。保留處理歷史與前後差異。
  4. 部門職務示例可用來展示員工後續可見模組變化；跨公司異動保留原任職／薪資來源，實際帳號與公司權限仍須另行核定。
前往操作 →
07考核目標、比重與結果
  1. 主管選被指派的考核，填工作目標、期間、評分尺度及目標比重；比重需合計 100%，送 CEO 確認。
  2. CEO 可核對或退回目標，並設定本期兩層評核合成比重；確認後保存本期快照。
  3. 主管填分數、實際成果與評語，再交 CEO 評核；CEO 可退回補充或完成第二層評分。
  4. 切員工查看結果。已設定比重顯示公式與合成分數；未核定比重則保留兩層分數，不擅自合成或自動調薪。
前往操作 →
08工程工作、文件與變更
  1. 工程主管開專案，新增工作、指派可用的工程成員、設定期限與檢查項目。
  2. 被指派員工回報進度、完成項目並送驗收；主管可退回補充或驗收通過，保留每次回報。
  3. 在專案內查看文件版本、預算表與變更紀錄；變更保留原因、費用／工期影響與歷次版本。
  4. 工程專案與行政交辦分開；預算依提供的資料核對，不宣稱已有自動工程估價或正式請款串接。
前往操作 →
09採購到到貨、轉傳票
  1. 工程主管新增採購，填供應商、品項、數量、單價及說明，送出。
  2. 財務複核、CEO 核准；退回回到申請人補充。這是目前保留的示例路線，不是已核定的全部採購制度。
  3. 核准後由申請端登記到貨驗收；財務從同筆採購建立相關傳票草稿，不會重複建帳。
  4. 接續財務傳票的複核、核准與入帳流程。供應商仍在採購內，沒有加回獨立左側模組。
前往操作 →
10財務傳票、報表與沖銷
  1. 財務選公司，建立傳票或匯入 CSV；預覽不寫入，確認後仍為草稿，借貸必須平衡。
  2. 送出 → CEO 複核 → 董事長核准 → 財務入帳；各步分開，未入帳金額不進財務總覽。
  3. 入帳後查看分錄、總帳、試算與報表；若需更正，以沖銷傳票保留原帳，不直接改掉原始入帳紀錄。
  4. 會計關帳會檢查未完成單據；各公司帳務分開。本示例不會真的付款、連銀行或改正式帳冊。
前往操作 →
11薪資與社保
  1. 財務設定示例薪資項目，核對批次、員工及任職／發薪公司；保留本批次快照。
  2. 財務送件 → CEO 複核 → 董事長核准 → 財務定稿；退回重新補充，不能自審。
  3. 切換員工，在「我的薪資」查看自己的定稿薪資單。社保可記錄收據／辦理狀態。
  4. 薪資計算、法規與正式發薪資料仍需核定，這些操作不會支付真實薪資。
前往操作 →
12培訓與獎懲
  1. 人資建立課程，員工報名或由授權人員安排，再登錄出席與證照。
  2. 表揚／違紀保留登記、獨立審核、退回補充及結果；員工可針對自己的紀錄提出申覆。
  3. 切換審核人處理申覆並留下回覆；不能靠改畫面文字改掉原始紀錄。
前往操作 →
13行政交辦
  1. 目前保留可操作的交辦示例；哪些行政工作真的要納管，仍待 KYD 確認。
  2. 建立事項、指定獨立複核／核准角色 → 送審 → 核准後指派執行人與里程碑。
  3. 執行人更新進度、送交完成；驗收人可退回補充或驗收。透過待辦交接，不用以「查看流程」按鈕代替實際操作。
前往操作 →

仍需核定或外部配合

  1. 簽核與授權：董總的正式簽核表、具體人員、代理、跨部門／跨公司條件。現有角色路線可試，不能當作已核定制度。
  2. 假別與計薪：依現行適用法規及公司資料核對假別、給薪、佐證、起算／結轉與不足額規則。跨月假勤尚未取得分攤資料時列「待拆分」，不將整筆時數重複計入兩個月；打卡參考工時不等於薪資工時。
  3. KPI：各職務目標、項目／層級比重、評分標準、主管或系統評分、週期與權限。系統支援設定與評核，內容仍由 KYD 決定。
  4. 總覽與提醒：鄧總最終指標、可見公司／部門、更新頻率，及證件適用對象、提醒天數與收件人。站內提醒已可操作；對外 Email／推播尚未接通。
  5. 業務界線：哪些行政交辦要納管、工程請款是否納入、正式帳冊／匯入匯出格式與財務部署。
  6. PMS 與外部介面：Richard 的資料規格、銀行／門禁／租客帳單與代收款界線，需要共同對接。ERP 保留入口，不宣稱這些串接已完成。

這次怎麼驗證

  • 220 項自動流程／權限測試通過：含退回重送、角色交接、獨立複核、核准、生效、公司／部門範圍、負數額度、來源保留與舊資料相容。
  • 電腦與手機瀏覽器實際完成請假退回、補充重送、複核、核准；確認月曆與原崗位清單一起反映衝突。
  • 兩種版面各檢查 12 個模組／畫面，以及英文、高棉文顯示；無頁面執行錯誤或整頁水平溢出。
  • 這些檢查證明目前示例的上述操作可執行，不等於法規、正式薪資、真實設備或外部系統驗收已完成。
