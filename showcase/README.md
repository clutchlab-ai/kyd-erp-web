## 直接启动（推荐）

双击 **Wharton_ERP_离线展示版.html**，使用 Chrome、Edge 或 Safari 打开。不需要安装 Python、联网、登录或填写密钥。代码、样式与语言转换字典都在 HTML 中。

手机尺寸演练可打开 **Wharton_ERP_手机离线展示版.html**。实际手机也可使用发布的网站 mobile.html；电脑和手机各自保存操作，不会同步。

## 文件夹方式

Mac 双击 launch.command；Windows 执行 `py -m http.server 8872 --bind 127.0.0.1`；Mac/Linux 执行 `./start.sh`。浏览器打开 http://127.0.0.1:8872/。这一方式需要 Python 3，但不需要联网。停止时按 Ctrl+C。

## 开场准备

1. 打开页面，预设为简体中文、暹光制造示范厂、董事长。
2. 顶部可切换角色和语言；手机点头像旁的“切换”。
3. 每轮演示前点顶部“重新演示”，再确认重设。全部还原为初始虚构案例。
4. 具体步骤见 **排练操作.html**。四分钟请假、两分钟董事长、两分钟工厂，按需要选择。

## 本版新增

- 工厂总览、订单进度、物料与库存、生产日报。
- 班组长日报提交后，订单、库存、缺料与董事长提醒同步变化。
- AI 洞察：预写简报、三类提醒、三组问答图表、一键转跟进待办。
- 默认简体中文，保留繁体、English、ខ្មែរ。新工厂与 AI 页面先提供中文；英文、高棉文翻译待补，切换后会提示。

## 展示边界

全部公司、员工、供应商、薪资、订单和金额均为虚构。数据只保存在当前浏览器；不同浏览器与设备不共享。无痕模式或浏览器清理可能清除操作；若禁止本地存储，关闭后不能保留。

工厂与 AI 页面是**功能预览.示范资料**：有前端联动，A6 状态仍为“只有画面”。没有生产后端、真实库存成本或外部 AI。提醒规则、单价和加班阈值是展示假设，不是企业政策或法定标准。点击核准不会执行付款；请假核准不会自动完成正式薪资扣算。

现有 KYD 线上系统未由本展示包修改。Kroma 的出勤整合在展后处理，合并规则和验收草案另归 B 包。
