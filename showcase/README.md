会展展示版 · 2026-11-26 修订 · 画面日期 2026-11-27

## 展示入口

**Wharton_ERP_离线展示版.html** 为电脑独立展示文件，已包含程式、样式与语言转换字典，可直接在浏览器中运行，无需联网、登录、安装套件或提供密钥。本次操作验证使用 Chromium。

**Wharton_ERP_手机离线展示版.html** 为手机尺寸展示入口。发布网站的 mobile.html 提供相同的手机界面；各设备分别保存操作，不进行实时同步。

## 源码运行环境

原始码为 HTML、CSS 与 JavaScript。本机服务器运行方式需要 Python 3：

| 环境 | 启动入口 |
|---|---|
| macOS | launch.command |
| macOS／Linux | `./start.sh` |
| Windows | `py -m http.server 8872 --bind 127.0.0.1` |

本机访问地址为 `http://127.0.0.1:8872/`。终端机的 Ctrl+C 用于停止服务器；本机运行不需要外部网络。

## 展示配置与数据状态

- 初始配置：简体中文、暹光制造示范厂、董事长角色；画面日期固定为 2026-11-27。
- 角色与语言选择位于页面顶部；手机角色入口为头像旁的“切换”。
- “重新演示”清除当前浏览器的演示操作，并恢复初始虚构案例。
- **排练操作.html** 记录各演示情境的操作步骤、角色交接及系统结果。

## 本次交付范围

- 工厂总览、订单进度、物料与库存、生产日报。
- 班组长日报提交后，订单、库存、缺料与董事长提醒同步变化。
- AI 洞察：预写简报、三类提醒、三组问答图表、一键转跟进待办。
- 默认简体中文，保留繁体、English、ខ្មែរ。新工厂与 AI 页面先提供中文；英文、高棉文翻译待补，切换后会提示。

## 功能现况与交付范围

全部公司、员工、供应商、薪资、订单和金额均为虚构。数据只保存在当前浏览器；不同浏览器与设备不共享。无痕模式或浏览器清理可能清除操作；若禁止本地存储，关闭后不能保留。

工厂与 AI 页面是**预览 · 演示数据**：有前端联动，A6 状态仍为“只有画面”。没有生产后端、真实库存成本或外部 AI。提醒规则、单价和加班阈值是展示假设，不是企业政策或法定标准。点击审批不会执行付款；请假审批不会自动完成正式薪资扣算。

现有 KYD 线上系统未由本展示包修改。Kroma 的出勤整合在展后处理，合并规则和验收草案另归 B 包。

## 源码与重建

- index.html / mobile.html：电脑、手机入口。

本包不含正式账号、API 密钥或数据库连接。不使用外部字体、CDN 或后端 API。
